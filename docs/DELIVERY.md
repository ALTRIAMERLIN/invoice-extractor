# Portfolio deliverables

Personal demo project. All invoices and suppliers are fictional. Not a client project.

| Item | Location |
| --- | --- |
| Application and dependencies | `app.py`, `invoice_extractor/`, `requirements.txt` |

| Fictional PDFs and expected data | `samples/` |
| Automated tests and validation notes | `tests/`, `docs/VALIDATION.md` |
| Upwork title, description, role, tags and upload order | `deliverables/UPWORK.md` |
| Cover in the established portfolio layout | `deliverables/cover.png` (2000×1500) |

| Finished demonstration | `video/out/invoice-extractor-demo.mp4` (67 s, 1080p60) |

The public source includes the runnable application, tests and customer-facing demonstration
assets. It does not include the personal video-template package or the original production
capture cache. Ordinary application use needs neither of them.

The cover's UI panel is a crop of the real four-invoice batch. The three screenshots are original
1920×1080 frames decoded to PNG without UI edits. The video combines real app footage with
MotionGit framing and captions; its ending table summarizes independently verified export data.

The Upwork kit is prepared for posting. A hosted video URL and a published Upwork portfolio
entry are separate from this source-code release. Follow `deliverables/UPWORK.md` for fields,
media order and the source link.
